# Privacy Policy

_Last updated: November 19, 2026_

## The website

orchardcore.net is a static website. It does not require an account, does not collect personal information through forms, and does not use its own cookies or tracking technologies. Like any web host, the server or content delivery network that serves the site may keep standard technical logs (such as IP address and requested page) for security and operational purposes.

## Orchard Core Videos tool

Orchard Core Videos is an internal tool used by maintainers of the Orchard Core open source project. It uploads videos that the Orchard Core project produces to the project's own YouTube channel, and updates their descriptions. It is not offered to the public and does not collect data from visitors or end users.

To do this, the tool asks the channel's owner to sign in with Google and grant these permissions:

- `youtube.upload`, to upload the project's videos.
- `youtube.force-ssl`, to update the title, description and chapters of those videos.

  The tool uses the access only for these purposes. It does not sell, share or transfer Google user data to third parties, and it does not use that data for advertising. Its use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Access can be revoked at any time at <https://myaccount.google.com/permissions>.

  ## Third-party services

  Videos are hosted on YouTube and embedded in the Orchard Core documentation. YouTube and Google handle data under their own policies: <https://policies.google.com/privacy>.
